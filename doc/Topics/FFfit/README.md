# FFfit / Force-Field Fitting

This folder holds documentation for the Python-based Hessian/force-field fitting workflow (`tests/tSiNCs/test_FFfit.py`) and related topics. It covers the mode-basis least-squares fit, bond/angle/dihedral parameter maps, and vibrational frequency comparisons against PySCF reference data.

- [HessianFit.chat.md](HessianFit.chat.md) — informal chat/development log for the FFfit workflow
- [Dihedral_Torsion.md](Dihedral_Torsion.md) — topical audit of the dihedral/torsion term implementation and open issues
